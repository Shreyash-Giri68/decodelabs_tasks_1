# Responsive Frontend Portfolio Website

This is a beginner-friendly portfolio website created using only HTML5, CSS3, and simple JavaScript.
It is designed to be responsive on both mobile and desktop screens, with a clean layout and easy navigation.

## Project Files

- `index.html` - The main page with semantic sections: header, navigation, hero area, about, projects, contact, and footer.
- `style.css` - Styling with Flexbox for layout, CSS Grid for project cards, and responsive mobile behavior.
- `script.js` - Simple JavaScript used to toggle the mobile hamburger menu.
- `README.md` - This file, with setup instructions and a short project overview.

## How to Run

1. Open this folder in your code editor.
2. Open `index.html` in your browser.
3. You can also use the browser's live preview feature if your editor supports it.

## What You Will Learn

- Semantic HTML structure using `<header>`, `<nav>`, `<section>`, and `<footer>`.
- Pure CSS layout techniques using Flexbox and CSS Grid.
- A beginner-level JavaScript toggle for a mobile navigation menu.

## Notes for Beginners

- No external frameworks are used.
- The layout is responsive using a media query for smaller screens.
- `script.js` keeps the JavaScript simple and easy to understand.

Feel free to customize the text, colors, and project cards to match your own style. Happy coding!
